          Downloading the tools
          
        
          The app needs three programs before the first download.
          
        
            
        
            
        
            
      
            
    
            

    
            
      
            
        
            Settings
            
        
            
          Downloads at once
          
            
            
            
            
          
            
        
            
        
            
          Copied links
          
        
            
        
            
          Transcripts
          
        
            
        
            Transcripts finish several times faster on an NVIDIA card. Switching it on downloads the larger copy of the speech program made for those cards.
            
        
            
          Words to get right
          
        
            
        
            One name per line, which the speech program listens for in every transcript. When it still writes one wrong, add a line like Flaude = Claude and every Flaude in the transcript becomes Claude.
            
        
            
          Sign-in
          
        
            
        
            Instagram, members-only and age-restricted videos need it. Links sent from the browser extension carry the browser's own sign-in.
            
        
            
          yt-dlp
          
          
        
            
        
            The app updates yt-dlp once a day since YouTube changes how it serves videos every few weeks. Press Update yt-dlp when a download fails that worked before.

            Install the browser extension
            
        
            The extension adds Download with Video Downloader to the right-click menu in Chrome and Edge, and its icon lists every video on a page. Keep this app open while you use it.
            
        
              
          
            1. Press Open the extension folder below and leave the window open.
              2. 
          
            2. In Chrome, type chrome://extensions in the address bar and press Enter. In Edge, type edge://extensions.
              3. 
          
            3. Switch on Developer mode at the top right of that page. In Edge it is in the left column.
              4. 
          
            4. Press Load unpacked and pick the Video Downloader extension folder from step 1, which is in Documents.
              5. 
          
            5. Click the jigsaw icon next to the address bar and press the pin beside Video Downloader to keep its icon in view.
              6. 
        
            
        
            After the app updates, press the reload arrow on the extension's card in chrome://extensions.
